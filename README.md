# إسلام داود — موقع شخصي وخدمات رقمية

موقع شخصي بلغة عربية (RTL) لعرض خدمات **إسلام داود**: تصميم وتطوير المواقع والمتاجر
الإلكترونية، التسويق الرقمي، وإدارة المحتوى والحسابات على منصات التواصل الاجتماعي.

## المميزات
- تصميم عصري متجاوب مع جميع الأجهزة (Responsive)
- دعم كامل للاتجاه من اليمين لليسار (RTL)
- قسم للخدمات، ومميزات "لماذا تختارني"، ونموذج تواصل
- بدون أي إطار عمل — HTML و CSS و JavaScript خالص
- تحسينات SEO ووسوم Open Graph

## الملفات
| الملف | الوصف |
|------|-------|
| `index.html` | صفحة الموقع الرئيسية |
| `styles.css` | التنسيقات والتصميم |
| `script.js` | القائمة، التأثيرات، ونموذج التواصل |

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
```

ثم افتح: <http://localhost:8000>

## قبل النشر — عدّل بيانات التواصل
في `index.html` استبدل القيم النائبة:
- رقم الهاتف / واتساب: `[ضع رقمك هنا]`
- الموقع: `[ضع موقعك هنا]`

نموذج التواصل حاليًا يعمل في الواجهة فقط؛ لإرسال الرسائل فعليًا اربطه بخدمة مثل
Formspree أو Netlify Forms أو خادم خاص بك.

## النشر (اختياري)
يمكن نشر الموقع مجانًا عبر **GitHub Pages**: من إعدادات المستودع → Pages → اختر فرع `main`.
